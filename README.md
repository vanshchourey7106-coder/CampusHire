# CampusHire

**CampusHire** is a lightweight, web-based campus recruitment and placement management application built with vanilla HTML, CSS, and JavaScript. It provides a clean, responsive, and dependency-free interface to streamline campus hiring workflows.

## Features
- **Campus Drive & Job Listings:** Browse and manage placement opportunities.
- **Application Tracking:** Track student applications and recruitment progress.
- **Responsive UI:** Built with pure HTML, CSS, and JavaScript for fast, client-side interactivity.

## Project Structure
```text
CampusHire/
├── index.html                   # Main application entry point
├── style.css                    # Styling and layout rules
├── app.js                       # Core application logic and interactivity
└── CampusHire_Presentation.pptx # Project overview and presentation slides
```

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/CampusHire.git
   ```
2. Navigate to the project directory:
   ```bash
   cd CampusHire
   ```
3. Open `index.html` directly in your browser (or launch it using a local server such as VS Code's Live Server extension).
